# Watching Paint Dry

Todo o contexto deste projeto (premissa, stack, convenções, estado atual, plano de ação) está em
`PROJETO.md`, na raiz. Leia esse arquivo antes de propor ou implementar qualquer coisa aqui.

Este arquivo (`CLAUDE.md`) é só o ponteiro — de propósito não carrega o conteúdo completo
automaticamente em toda sessão, pra não inflar contexto com o plano de ação (que só cresce). Se
`PROJETO.md` não existir por algum motivo, ver histórico de commits / `CONCEITO-DO-JOGO.md` e
`PLANO-EVOLUCAO-STEAM.md` como fallback.
